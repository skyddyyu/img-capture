# 工程设计与实现说明

PRD 已覆盖开发所需的核心需求；本文件补充工程设计、界面决策和实际运行边界。

## 结构与数据流

工具栏用户操作直接打开浏览器侧边栏，同时尝试按需注入 `picker`。侧边栏命令经 Background 转发到当前页面；Content Script 只负责选取、提取和返回数据。React 不注入业务页面。

扫描按约 8 ms 时间片让出主线程。结果每次传输最多 100 条，由 Background 按 URL 合并。完成时刷新全部资源的最终引用数量，最后单独提交完成消息。扫描状态与缩略图网络加载相互独立。

Background 消息串行处理，避免存储读写和取消发生竞争。任务使用随机 `taskId` 和页面实例 `documentToken`，核对扩展来源、标签页和主 frame；旧任务消息不能覆盖新任务。来源页面的 DOM 元素引用只存在于 Content Script，不序列化到存储。

## 模块选择

页面只增加一个隔离样式的覆盖层。透明玻璃层拦截选取操作，包含 iframe 上方的指针事件；命中检测时临时关闭覆盖层的指针响应，读取底层文档元素后恢复。iframe 内部和 Shadow DOM 内部仍不扫描。

高亮通过动画帧合并更新。选区旁工具条提供扩大、缩小、提取、取消，键盘操作保持可用；工具条展示保守的区域描述，把 CSS 选择器放到次级位置。扩大后在已选区域内移动不会重置调整路径，跨越工具条间隙也保留范围。选取结束移除覆盖层和监听器，不改动业务节点的属性或原有样式。

SPA 导航通过 Navigation API、`popstate`、`hashchange` 与浏览器 `tabs.onUpdated` 共同处理，不在未启动时注入轮询脚本。

## 界面决策

- 使用浅色底、绿色主操作、图片卡片网格。无需外部字体、图标 CDN 或 UI 组件库。
- 结果页收起介绍，只保留紧凑工具栏；320～600 CSS 像素侧边栏适配，图片等比完整显示。默认中号缩略图下，320/360/440 × 720 CSS 像素首屏可浏览两行缩略图。小号网格在宽侧栏使用三列，大号网格在窄侧栏使用单列。
- 文字至少 12px，文件名和主要操作使用 13～15px；列表地址和详情完整地址支持聚焦全选，保留 URL 参数与 fragment。
- 详情在侧边栏内部切换，尺寸、版本与主要操作优先展示，来源节点和技术信息默认折叠。大图默认适应窗口，支持扩大预览区域、25%～400% 缩放、左右键切换、Esc 返回；返回时恢复对应卡片焦点，虚拟列表先定位再恢复焦点。
- 地址是主要产物，卡片与详情预览失败时均可重试或打开链接。空结果和部分完成提供调整范围操作；滚动后可显式追加采集，按完整 URL 合并，最多保留 1,000 条。
- 超过 100 张图片使用固定行高的虚拟列表；可视区域附近才加载预览。
- 预览队列并发最多 6，单项 15 秒超时；离开视图取消无人订阅的加载，详情只维持当前大图。
- 使用本地 PNG 工具栏图标和内联 SVG 界面图标，不依赖生成式图片服务。

## 存储与恢复

`storage.session` 以 `tab:<id>` 保存每个标签页的最近完成结果、单份 `previousResult` 撤销快照及当前状态。仅成功完成扫描时替换快照，取消或失败保留最近完成结果；浏览器重启、扩展重新加载或更新后会话清除。侧栏重新打开与 Service Worker 重启可恢复快照。

“恢复上次结果”由 Background 串行处理：替换结果、清除快照、更新任务 ID 并取消旧任务，防止迟到的扫描覆盖恢复结果。由于 DOM 引用不序列化，恢复后要求重新选择范围才能继续扫描，复制和查看不受影响。

所有会话数据预算 5 MiB。优先回收其他标签页最久未查看的结果并留下提示；随后释放当前标签页的撤销快照并提示；当前结果仍过大则截断且保留“部分完成”原因。每张图片保存最多 20 个来源详情。

Service Worker 重启后恢复完成结果；进行中的任务标为中断，同时要求 Content Script 取消旧任务。重新提取仍需页面中的模块引用存在；页面刷新后必须重新选择。

`storage.local` 分别保存 `preferences:view`、`preferences:thumbnailSize` 与 `preferences:onboardingCompleted`，无须新增权限。显示偏好和引导状态在浏览器重启后保留，关闭来源标签页只清除会话结果。首次提取成功（含空结果、部分完成）后自动收起引导，也支持手动收起；快捷键与说明始终可打开。

偏好按字段写入并串行保存，避免快速调整互相覆盖；监听 `storage.onChanged` 同步多个侧栏。初始读取不会覆盖加载期间的调整，无效值回退默认；保存失败保留本次显示状态并在设置中提示，后续调整可再次保存。

三档尺寸的卡片高度、预览高度和虚拟行高由 `THUMBNAIL_LAYOUT` 共同决定，通过 CSS 变量应用，避免虚拟滚动占位高度和实际卡片脱节。设置弹窗支持 Tab 焦点循环，关闭后焦点回到入口。

## 首版限制

- 构建面向 Chrome 116+ 与现代 Edge；实际兼容承诺以验证记录为准，未把框架能生成构建视为浏览器实测。
- 不读取图片二进制或响应头；格式只按地址推测，固有尺寸取自浏览器。
- `ImageResource.previewStatus` 在侧边栏内存维护，不持久化网络加载失败状态，重新打开面板可重新尝试。
- `firstSeenOrder` 由资源数组顺序表达；消息请求 ID 只用于侧边栏命令，扫描由任务 ID 追踪。
- 隐藏且未应用的 CSS 图片、未生成 DOM 或未暴露资源地址无法保证发现。
- 浏览器原生侧边栏宽度和开关由浏览器管理，插件不修改用户浏览器布局偏好。
- 商店资料、账号申请与商店提交不属于本地软件交付范围。
