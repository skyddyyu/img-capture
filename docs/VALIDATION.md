## 浏览器覆盖范围

28 组端到端检查覆盖原有 16 组场景、P0/P1 的 7 组交互回归，以及 P2 的 5 组偏好与引导回归：

1. 初始界面、320/440/600 CSS 像素布局与无水平溢出。
2. 元素选取、父级调整、阻止网页点击跳转、模块范围与去重。
3. CSS 背景、伪元素背景、懒加载候选、隐藏 DOM 图片和 `currentSrc`。
4. 图片列表、预览失败、详情、缩放、上一张与下一张。
5. 剪贴板被拒绝时的完整地址手动复制回退。
6. 取消选取后保留结果并恢复网页事件。
7. 空结果、父子调整、加载新图片后重新扫描、模块移除提示。
8. 不支持的协议、Canvas、内联 SVG、iframe 与 Shadow DOM 边界。
9. 页面导航后结果过期、禁止对旧模块重新扫描。
10. 标签页隔离，以及未授权新标签页禁止注入。
11. Service Worker 重启后恢复完成结果。
12. 浏览器受限页面的错误提示。
13. 常规模块性能采样，以及任务边界处取消扫描。
14. 20,000 个元素遍历上限。
15. 1,000 个资源上限和大量结果的虚拟列表。
16. 5 MiB 会话元数据预算、截断与明确的部分完成状态。
17. 收起介绍、两列网格，以及 320/360/440 × 720 CSS 像素首屏可完整看到两行缩略图。
18. 网格/列表切换、完整地址聚焦全选、关键文字至少 12px、窄侧栏无水平溢出。
19. 详情关键操作优先、技术信息默认折叠、扩大预览、左右键切换、地址编辑键不触发切换、Esc 返回恢复焦点。
20. 选区旁工具条的扩大、缩小、提取、取消，操作不触发底层网页点击。
21. 侧栏重新打开后恢复上次结果、旧任务完成消息不能覆盖恢复结果，恢复后采集需重新选择范围。
22. 追加采集按完整 URL 去重、保留旧链接及签名参数、可撤销追加。
23. 在 1,000 张图片的虚拟网格和列表中，切换至未渲染图片后返回可恢复焦点，之后仍能自由滚动。
24. 无效的视图、缩略图大小或引导状态回退到可用默认值。
25. 首次提取后引导收起、新标签页只显示简洁入口；手动收起后重新打开侧栏保持状态，快捷键说明可随时查看。
26. 显示偏好在侧栏重新打开后恢复、多个侧栏同步；320px 设置窗口无水平溢出，Tab 焦点循环、Esc 关闭后恢复入口焦点。
27. 模拟偏好保存失败时保留本次显示状态并提示；恢复存储后再次调整可保存并清除错误。
28. 三档缩略图分别组合网格和列表，在 1,000 张图片中均可到达末尾、打开正确图片并返回恢复焦点，虚拟化保持有效。

容量回归曾发现初始选区工具条遮挡页面左上角的选取入口，修复为初始停靠底部、悬停后贴近选区；修复后两浏览器完整回归均通过。

URL 复制测试逐行比对完整地址，保留签名参数与 fragment。剪贴板成功写入采用浏览器标准 API；自动化不改写用户系统剪贴板，主要验证拒绝回退路径。

## 性能

使用本地固定页面，根元素加 5,000 个子元素，共 5,001 个元素，其中 200 个唯一图片地址；连续 20 次扫描。时间取自提取器内部，包含扫描、去重、分批传输等待，不包括远程图片解码与整个侧边栏绘制耗时。

| 浏览器 | 首次扫描 | 扫描 p95 | 样本数 |
| --- | --- | --- | --- |
| Chrome 154 | 62 ms | 112 ms | 20 |
| Edge 155 | 109 ms | 182 ms | 20 |

Chrome 本次全部样本为 62～115 ms，Edge 为 109～191 ms，均达到 PRD 的扫描 p95 ≤ 2 s 目标。样本和精确版本见两个浏览器的 `.artifacts/*-e2e-report.json`。悬停反馈 p95、预览网络成功率和复杂真实网站性能未做独立量化，不以该测试推断所有网站表现。
