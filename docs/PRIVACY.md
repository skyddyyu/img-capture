# 模块取图隐私说明

版本：0.1.0

模块取图在用户主动点击工具栏、选择网页区域后，读取该区域的图片地址、元素摘要、图片说明和尺寸等必要信息，生成浏览器侧边栏中的结果。

## 数据处理

- 页面扫描、URL 去重和图片信息整理均在本机完成。
- 不设自建服务器、账号系统、云同步、广告或远程数据统计。
- 不上传网页内容、网页地址、图片地址或图片二进制。
- 仅在浏览器会话内保存当前结果及最多一份用于撤销的上次结果，按标签页隔离；关闭来源标签页会清除其结果。浏览器重启或扩展重新加载、更新后会话数据清除。
- 网格/列表、缩略图大小及是否完成首次引导保存在本机，浏览器重启后保留；这三项偏好不包含网页或图片地址，不上传或云同步，卸载扩展时清除。
- 不保存网页完整 HTML，不读取 Cookie、表单内容或用户浏览历史。
- 生产代码不将图片 URL 或页面信息写入调试日志。

## 预览与外部网络

图片预览直接访问原图片地址，原服务器可能收到普通图片请求及浏览器允许携带的相关信息。插件设置不发送 Referer，但不能控制原服务器的记录行为。复制链接不会上传链接；用户选择打开图片地址时，浏览器访问对应网站。

没有可用网络或原站拒绝请求时，预览可能失败。插件不绕过登录、防盗链或访问限制。

## 权限

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 用户主动操作后临时读取当前网页 |
| `scripting` | 按需注入模块选取和提取脚本 |
| `sidePanel` | 在网页旁展示扩展界面 |
| `storage` | 保存会话中的提取结果及本机显示偏好、引导状态 |

生产构建无常驻全站主机访问、Cookie、网络监听或下载权限，不在所有网站自动运行。剪贴板操作仅由用户点击复制按钮触发；浏览器拒绝自动复制时提供手动复制入口。

删除扩展即可停止其运行。可关闭来源标签页清除对应会话结果，或重启浏览器清除全部会话结果。
